================================================================
 Day 5 — 物聯網系統與應用 (iPAS IoT 考科二 · 學科)
 對應證照: iPAS AIoT 應用工程師(物聯網類)-初級 考科二
 重要性: ★★★★★ (單選題 50 題 / 75 分鐘)
================================================================

【今日目標】
- 能規劃軟硬體整合架構並判斷故障
- 認識雲端資料收集、資料庫與 API 設計
- 理解開源軟硬體授權規範
- 連結智慧製造流程優化與成本控制

----------------------------------------------------------------
1. 系統元件與架構 (軟硬體整合規劃)
----------------------------------------------------------------
* 感知端 → 閘道器 (Gateway) → 網路 → 雲端平台 → 應用
* 邊緣運算 vs 雲端運算 的取捨 (延遲/頻寬/隱私 vs 算力)
* 系統元件: 感測器、MCU/SBC、通訊模組、閘道器、伺服器
* 規劃要點: 可擴充性、可靠性、互通性、安全性

----------------------------------------------------------------
2. 簡易系統故障問題判斷與排除
----------------------------------------------------------------
* 排查順序: 供電 → 連線 → 感測器 → 通訊 → 平台
* 常見問題: 訊號雜訊/干擾、IP/埠設定、憑證錯誤、逾時、
    裝置離線、資料格式不符
* 工具: 日誌 (Log)、封包擷取、Ping/Telnet、平台監控

----------------------------------------------------------------
3. 物聯網資訊安全
----------------------------------------------------------------
* 三大面向: 裝置安全、通訊安全、雲端/資料安全
* 機制: 身分驗證、授權、加密 (TLS/憑證)、安全開機、
    韌體簽章與 OTA 更新
* 風險: 弱密碼、未更新韌體、資料外洩、設備被綁架

----------------------------------------------------------------
4. 物聯網硬體設計基礎
----------------------------------------------------------------
* I/O 通訊與控制: 數位 I/O (GPIO)、類比輸入、PWM 控制
* 通訊介面: UART / I²C / SPI (見 Day4)
* 開源硬體: Arduino、Raspberry Pi、Micro:bit
* 開源硬體授權規範: 依開源硬體授權 (如 CERN OHL) 使用與再發布

----------------------------------------------------------------
5. 雲端環境數據收集與平台設計
----------------------------------------------------------------
* 資料交換格式: JSON (最常用)、XML、CSV、MessagePack
* 資料庫:
    - 關聯式 (SQL): 結構化、強一致性 (MySQL/PostgreSQL)
    - NoSQL: 文件 (MongoDB)、鍵值 (Redis)、時序 (InfluxDB)
* 資料流: 收集 → 傳輸 → 儲存 → 處理 → 視覺化
* Web API: RESTful (GET/POST...), MQTT 訂閱
* 開源軟體規劃與授權: GPL / MIT / Apache 差異, 商用合規

----------------------------------------------------------------
6. 智慧製造流程優化與成本控制
----------------------------------------------------------------
* MES (製造執行系統): 生產現場管理、追溯
* ERP (企業資源規劃): 資源/訂單/庫存整合
* 機聯網: 設備資料上雲 → 可視化 → 分析 → 優化
* 預測性維護: 由感測數據預測故障, 降低停機成本
* 成本控制: 減少停機、良率提升、能耗優化、人力配置
