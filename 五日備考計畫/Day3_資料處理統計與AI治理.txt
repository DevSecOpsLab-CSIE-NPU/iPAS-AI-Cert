----------------------------------------------------------------
1. 資料類型與儲存
----------------------------------------------------------------
* 結構化資料: 表格 (SQL DB)
* 半結構化: JSON, XML, CSV (彈性 schema)
* 非結構化: 影像、影片、語音、自由文本
* 資料倉儲 Data Warehouse: 結構化、已清理、適合分析
* 資料湖 Data Lake: 多類型原始資料、彈性高
* 資料湖屋 Data Lakehouse: 兩者混合 (Databricks)

【陷阱題】影像是非結構化, 不是半結構化

----------------------------------------------------------------
2. 資料清理
----------------------------------------------------------------
* 缺失值: 刪除 / 平均/中位/眾數 / 預測補值
* 異常值偵測:
    - Z-score: |Z| > 3 視為異常
    - IQR 法: < Q1-1.5*IQR 或 > Q3+1.5*IQR
    - 箱型圖視覺化
* 異常值處理:
    - 直接刪除 (要謹慎) / Log 轉換 / Winsorize 截斷
    - ★ 標準差/平均數本身不是處理方法, 是檢測指標
* 資料飄移 Data Drift: 輸入特徵分布隨時間變化 → 模型需重訓

----------------------------------------------------------------
3. ⭐ 115 新考點：資料洩漏 (Data Leakage) 與前處理順序
----------------------------------------------------------------
【鐵則】先切分 (train/test), 再只用訓練集 fit 任何轉換
* 標準化/正規化: 先分割, 僅以訓練集計算統計量, 再套用測試集
* 特徵篩選: 不可在含測試集的全體資料上計算相關性
* 過採樣 SMOTE: 必須在切分後、且只對訓練集執行
* 降維 (LDA/PCA): 須納入交叉驗證流程一起做

【常見錯誤 (皆為陷阱選項)】
* 分割前對全體資料算統計量 → 資料洩漏
* 在全體資料上做特徵篩選 → 資料洩漏
* 先 SMOTE 再切分 → 合成樣本洩漏至測試集, 指標虛高
* 先全體 LDA 降維再交叉驗證 KNN → 資料洩漏

----------------------------------------------------------------
4. ⭐ 115 新考點：類別失衡與 SMOTE
----------------------------------------------------------------
* SMOTE: 依少數類樣本的特徵空間, 合成產生新的少數類樣本
    (不是刪多數類、不是調 loss 權重、不是重新分割)
* class_weight = 調整損失函數權重
* Random Under-sampling = 隨機刪多數類
* 極度不平衡 (如 1.6%) 下 AUC-ROC 可能過度樂觀 → 用 PR-AUC

----------------------------------------------------------------
5. 敘述統計
----------------------------------------------------------------
* 集中趨勢: 平均數 (受極端值影響) / 中位數 (抗極端值) / 眾數
* 變異性: 標準差 / 變異數 / 全距 / 四分位距 IQR
* 中位數是「集中趨勢」, 不是「變異性」(★陷阱)
* 偏態 Skewness: 右偏 → 平均 > 中位
* 常態分布: 對稱鐘形, 68%-95%-99.7% 規則

----------------------------------------------------------------
6. 視覺化選擇 (★情境配對題)
----------------------------------------------------------------
* 散佈圖 Scatter: 兩數值變數關係 / 直方圖 Histogram: 單一變數分布
* 箱型圖 Boxplot: 分布摘要找異常 / 折線圖 Line: 時間趨勢
* 長條圖 Bar: 類別比較 / 圓餅圖: 占比 (不適合多類別)
* 熱圖 Heatmap: 關聯強度 / 雷達圖: 多維比較

【口訣】分布看直方/箱型 → 關係看散佈/熱圖 → 時間看折線 → 類別看長條

----------------------------------------------------------------
7. 大數據工具與生命週期
----------------------------------------------------------------
* MapReduce: Map 切分 → Reduce 彙總 (Hadoop 核心)
* Hadoop: HDFS + MapReduce / Spark: 記憶體運算較快
* ETL: Extract → Transform → Load ; ELT: 順序對調, 適合資料湖
* MLOps 生命週期: 資料收集 → 訓練 → 部署 → 監控 → 重新訓練
* MLflow: 管理 ML 實驗、模型版本、生命週期
* HITL (Human-in-the-Loop): 人類專家參與訓練/校正

----------------------------------------------------------------
8. 歐盟 AI Act 風險分級 (★每場 3~4 題)
----------------------------------------------------------------
* 不可接受風險 (禁止): 政府社會評分、操控人類行為、
    即時公共場所生物識別、情緒辨識用於職場/教育
* 高風險 (嚴格監管): 員工臉部辨識打卡、招募 AI、信用評分、
    保險核保、司法/執法/邊境、醫療診斷、教育評鑑、關鍵基礎設施
* 受限/有限度風險 (透明義務): AI 聊天機器人須告知「正在與 AI 對話」、
    Deepfake 必須標示
* 最小風險 (無限制): 垃圾郵件過濾、AI 遊戲、語音助理

【口訣】禁止→政府監控/社會評分；高風險→影響工作/權益/安全；
        受限→要告知是 AI；最小→日常便利型

----------------------------------------------------------------
9. 個資與隱私保護
----------------------------------------------------------------
* PII: 個人可識別資訊
* GDPR: 適用收集/處理歐盟個資的所有組織 (含台灣公司)
    權利: 存取權、被遺忘權、可攜權、反對權
    罰款: 最高 4% 全球年營收 或 2000 萬歐元
* 去識別化: 匿名化 (不可逆) / 假名化 (可逆) / K-匿名性 / 差分隱私
* 加密: 對稱 / 非對稱 / 同態加密
* 零信任架構 ZTA: 永不信任、持續驗證

----------------------------------------------------------------
10. AI 偏見、產業指引與安全 (略記)
----------------------------------------------------------------
* 偏見來源: 資料/標註/演算法/部署偏差
* 案例: Amazon 履歷 AI 歧視女性、COMPAS 假釋預測歧視
* XAI: SHAP, LIME, 決策樹本身可解釋；模型卡/資料卡
* 金管會金融 AI 指引: 治理、風險管理、消費者保護、人為監督
* 自駕車 SAE 等級 0~5 (L2 部分自動 / L5 完全自動)
* 攻擊: 對抗性樣本、資料投毒、模型竊取、成員推斷
* AI 導入順序: 需求評估 → 資料準備 → 模型開發 → 方案落地
    → 模型監控與重新訓練 → AI 價值擴散
