 對應科目: 初級 科目一 人工智慧基礎概論 / 中級 科目三 機器學習
 重要性: ★★★★★ (題數最多、科一成敗關鍵)
================================================================

【今日目標】
- 能在 5 秒內判斷情境屬於哪一種學習典範
- 看到指標公式能反推適用場景
- 能解釋過擬合/欠擬合並提出對策
- 看到模型名稱能立刻講出用途 (CNN/BERT/GPT/GAN/VAE)

----------------------------------------------------------------
1. 學習典範分類 (常考: 每場 3~5 題)
----------------------------------------------------------------
* 監督式 Supervised: 有標籤 → 分類 / 迴歸
    例: 預測客戶流失、信用評分、垃圾郵件分類
* 非監督式 Unsupervised: 無標籤 → 分群 / 降維
    例: 顧客分群、異常檢測、PCA 降維
* 半監督式 Semi-supervised: 少量標籤 + 大量未標籤
    例: 醫療影像僅部分有專家標註
* 強化學習 Reinforcement: 獎勵/懲罰訊號
    例: 自駕車、AlphaGo、推薦系統最佳化

【陷阱題】"在自駕車模擬中根據是否安全通過獲得獎勵" → 強化學習 (非非監督)

----------------------------------------------------------------
2. 經典演算法
----------------------------------------------------------------
* KNN: 基於距離、惰性學習、K 值決定鄰居數
* 決策樹: 可解釋、易過擬合、需剪枝
* 隨機森林: Bagging 集成、降低變異、抗過擬合
* SVM: 找最大邊界、核技巧處理非線性 (注意: 非深度學習)
* 線性迴歸 / 邏輯迴歸: 連續值 / 二分類
* K-means: 距離 / DBSCAN: 密度 (兩者差異必考)
* 樸素貝葉斯: 機率、文本分類常用

----------------------------------------------------------------
3. 模型評估指標 (公式必背)
----------------------------------------------------------------
* 混淆矩陣: TP, FP, TN, FN
* Accuracy = (TP+TN) / 全部
* Precision (精確率) = TP / (TP+FP)  ← 寧缺勿濫
* Recall (召回率) = TP / (TP+FN)     ← 寧錯勿漏
* F1 = 2 * P * R / (P+R)             ← 調和平均
* ROC / AUC: 衡量二分類門檻不變下的整體能力
* 迴歸: MAE, MSE, RMSE, R²

【情境題】醫療癌症篩檢: 重 Recall (寧誤判也不漏)
         垃圾郵件: 重 Precision (寧漏也別誤刪正常信)

----------------------------------------------------------------
4. 過擬合 vs 欠擬合
----------------------------------------------------------------
* 偏差 Bias: 模型太簡單 → 欠擬合
* 變異 Variance: 模型太複雜 → 過擬合
* 對策: 交叉驗證 / 正則化 (L1, L2) / Dropout / 早停 /
        增加資料 / 減少特徵 / 換較簡單模型
* K-fold 交叉驗證: 切 K 份輪流當驗證集

----------------------------------------------------------------
5. 特徵工程與選擇
----------------------------------------------------------------
* 特徵縮放: 標準化 (Z-score) / 正規化 (Min-Max)
* 類別編碼: One-hot (無序) / Label Encoding (有序)
* 缺失值: 刪除 / 平均/中位/眾數補值 / 模型預測
* 特徵選擇:
    - 過濾法 (Filter): 統計量篩選
    - 包裝法 (Wrapper): 模型評估
    - 嵌入法 (Embedded): L1 自動選擇
* 監督式特徵選擇: 看與目標變數的相關性
* PCA 降維: 找最大變異方向

----------------------------------------------------------------
6. CNN 與電腦視覺
----------------------------------------------------------------
* CNN 元件: 卷積層 (擷取特徵) → 池化層 (降維) → 全連接層
* 池化目的: 降尺寸、減計算、防過擬合
* 應用任務:
    - 影像分類 (Image Classification)
    - 物件偵測 (Object Detection): YOLO, Faster R-CNN
    - 語義切割 (Semantic Segmentation): 每像素分類
    - 實例切割 (Instance Segmentation)

【陷阱題】停車費計算 → 不是電腦視覺應用 (是規則計算)

----------------------------------------------------------------
7. RNN / Transformer / NLP
----------------------------------------------------------------
* RNN: 處理序列資料、有梯度消失問題
* LSTM / GRU: 解決長序列梯度問題
* Transformer: 注意力機制 Self-Attention, 並行運算
* BERT vs GPT (★必考):
    - BERT: 雙向、適合理解任務 (分類、問答)
    - GPT: 單向 (從左到右)、適合生成任務
* 詞嵌入 Word Embedding: 文字轉數值向量, 捕捉語義
    例: Word2Vec, GloVe, FastText

----------------------------------------------------------------
8. 生成模型架構
----------------------------------------------------------------
* GAN: 生成器 vs 判別器對抗訓練
* VAE: 編碼器-解碼器 + 機率潛在空間, KL 散度
* Encoder-Decoder: ChatGPT 採用此架構
* Diffusion Model: 去噪生成 (Stable Diffusion, DALL·E)
* SVM 不是深度學習 (★陷阱)

----------------------------------------------------------------
9. 訓練機制
----------------------------------------------------------------
* 反向傳播 Backpropagation: 計算梯度更新權重
* 梯度消失 / 爆炸: 深層網路常見問題
    對策: ReLU、Batch Normalization、殘差連接
* 激活函數:
    - ReLU: 隱藏層常用、解決梯度消失
    - Sigmoid: 二分類輸出
    - Softmax: 多分類輸出 (機率分布)
    - Tanh: -1 到 1
* 超參數: Batch size, Learning rate, Epoch 數
    Batch 變大 → 訓練快但記憶體吃緊、泛化能力可能下降

----------------------------------------------------------------
10. 遷移學習與模型優化
----------------------------------------------------------------
* 遷移學習 Transfer Learning: 預訓練模型 → 新任務微調
    優勢: 資料少也能訓練、節省時間
* Fine-tuning: 全參數微調
* LoRA: 低秩矩陣分解, 高效微調 (只訓練少量參數)
* 知識蒸餾 Knowledge Distillation: 大模型 → 小模型
* 剪枝 Pruning: 移除不重要權重
* 量化 Quantization: 降低數值精度 (FP32→INT8)
* 邊緣運算 Edge Computing: 減延遲、降頻寬、即時處理
