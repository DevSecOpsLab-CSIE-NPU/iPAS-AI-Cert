2. 提示工程 Prompt Engineering
----------------------------------------------------------------
* Zero-shot: 直接問
* Few-shot: 給範例後問
* Chain-of-Thought (CoT): 讓模型逐步推理
* Prompt 攻擊型態 (★必考):
    - Prompt Injection 提示注入: 使用者輸入操控模型偏離任務
    - Prompt Leakage 提示洩漏: 模型暴露不該透露的系統提示
    - Jailbreak 越獄: 繞過安全限制
* 對策: 輸入過濾、輸出檢查、權限分層、Guardrails

----------------------------------------------------------------
3. RAG 與微調 (★關鍵比較)
----------------------------------------------------------------
* RAG (Retrieval-Augmented Generation):
    - 檢索外部知識 + 生成
    - 優點: 不用重訓、即時更新、可追溯來源
    - 適合: 企業內部文件問答
* Fine-tuning 微調:
    - 修改模型參數
    - 適合: 改變模型風格、特定領域語氣
* RAG vs Fine-tune: RAG 快 (無需重訓), Fine-tune 深
* LoRA: 高效微調, 只訓練少量參數
* 蒸餾: 大模型壓成小模型
* 幻覺 Hallucination: LLM 自信地編造錯誤資訊
    對策: RAG、Temperature 調低、人工審核

----------------------------------------------------------------
4. No-code / Low-code 平台 (★ 約 5~10 題/場)
----------------------------------------------------------------
* No-code: 無需程式碼 (Make, Zapier, Bubble)
* Low-code: 少量程式 (Power Apps, OutSystems)
* 優勢: 開發快、降低門檻、原型驗證
* 限制: 客製化彈性受限、大規模/高效能不適合、
        廠商鎖定 (Vendor Lock-in)、複雜邏輯難實作
* 適用對象: 業務人員、PM、原型開發

----------------------------------------------------------------
5. AI Agent 與多模態
----------------------------------------------------------------
* AI Agent 核心能力:
    - 感知 Perception / 規劃 Planning / 工具呼叫 Tool Use
    - 記憶 Memory / 自主執行
    - ★ 不包含: 發明新技術
* AI 環境適應能力 = 泛化能力 Generalization
* 多模態: 同時處理文字 / 圖像 / 語音 / 影片
* CLIP: 將圖片與文字映射到同一嵌入空間

----------------------------------------------------------------
6. 115 新考點速記 (★115 年主軸，務必熟讀)
----------------------------------------------------------------
【Agentic AI / ReAct】
* ReAct = Reasoning and Acting: Thought → Action → Observation 循環
    適合: 探索式、路徑不固定、需自行判斷的任務
    不適合: 流程固定、規則明確
    ★ ReAct 由思維鏈 (CoT) 衍生; Zero-shot Learning 不是
* Multi-Agent: Orchestrator 分配任務 + Worker 執行
    ★ 容錯: 結果評估 → Retry / 重新分配, 並記錄失敗原因
    ★ 痛點: 各 Agent 缺乏 Context 同步

【MCP (Model Context Protocol)】
* MCP ＝ 模型與外部工具/系統互動的標準化協定 (手腳)
* RAG ＝ 補充模型知識來源 (記憶)
* MCP Server: 提供標準化工具與資料存取, 模型透過協定呼叫
* Skill: 封裝需 AI 語意理解的可重複使用能力模組 (≠ MCP)
* 「即時存取最新外部文件」→ MCP ; 「記住新知識」→ Fine-tuning

【Solution Graph 解決方案圖】
* 把問題解決步驟表示為節點與連結的有向無環圖 (DAG)
* 單次任務、用後即棄；Knowledge Graph 則是長期共用知識
* 優點: 分階段規劃與驗證, 降低幻覺
* ★ 不會自動糾正錯誤、不能完全避免虛構

【Context Engineering 上下文工程】
* 表格資料 → 轉成結構化 JSON / Markdown table 最佳

【Vibe Coding】
* 自然語言驅動 AI 生成程式碼, 多輪對話迭代, 適合快速原型
* 品質高度依賴提示詞精準度；上線前必經 審查/重構/安全測試
* Prompt Engineering / Vibe Coding / Low-Code / No-Code 要能配對

【AI 內容出處】
* SynthID: Google 不可見數位浮水印 (Gemini/Veo)
* C2PA (Content Credentials): 內容來源元數據 (Sora)
* 另一選項: 內部反向影像/音訊搜尋；★ 不包含「對外開放實時來源驗證介面」

【安全】
* Guardrails: 模型前後端獨立防護網, 即時攔截/過濾
* Jailbreak: 純對話誘導偏離設定; Injection: 夾帶外部指令
