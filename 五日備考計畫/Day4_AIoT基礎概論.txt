----------------------------------------------------------------
1. AI 基礎知識與應用
----------------------------------------------------------------
* AI ⊃ 機器學習 ⊃ 深度學習 (範圍由大到小)
* 機器學習: 監督式 / 非監督式 / 強化學習
* 深度學習: 類神經網路 (CNN 影像 / RNN 序列 / Transformer 語言)
* 邊緣運算 Edge Computing: 資料在終端就近運算
    優點: 低延遲、省頻寬、提升隱私；雲端: 大算力、集中管理
* AIoT = AI + IoT: 在物聯網裝置/邊緣導入 AI
    應用案例: 預測性維護、瑕疵檢測、智慧電表、智慧交通、智慧農業

----------------------------------------------------------------
2. 物聯網架構與功能 (三層架構 ★必考)
----------------------------------------------------------------
* 感知層 Perception: 感測器、致動器、RFID (蒐集/控制實體)
* 網路層 Network: 各種通訊技術與閘道器 (傳輸)
* 應用層 Application: 平台、資料處理、服務 (加值應用)
* 常見補充: 邊緣層 / 平台層 (Middleware)

----------------------------------------------------------------
3. 常見通訊協定與網路層技術 (★配對題必考)
----------------------------------------------------------------
【應用層 / 訊息協定】
* MQTT: 輕量、Publish/Subscribe、Broker 中介、適合低頻寬 IoT
* CoAP: 基於 UDP、RESTful、適合受限裝置 (類 HTTP)
* HTTP/REST: 通用、較重、Web API 常用
* AMQP: 企業級訊息佇列
【無線通訊技術】
* Wi-Fi: 高頻寬、短距、耗電較高
* BLE 藍牙低功耗: 短距、低功耗、穿戴裝置
* ZigBee: 低功耗、網狀 (Mesh)、智慧家庭
* LoRa / LoRaWAN: 長距、低功耗、低頻寬 (LPWAN)
* NB-IoT: 電信蜂巢式、廣覆蓋、低功耗 (LPWAN)
* 5G: 高頻寬、低延遲 (uRLLC / mMTC)
【辨識技術】
* RFID: 無線射頻辨識, 標籤(Tag) + 讀取器(Reader), 被動/主動
* NFC: 近距離 (約 4cm)、行動支付
【口訣】短距低功耗→BLE/ZigBee；長距低功耗→LoRa/NB-IoT；高頻寬→Wi-Fi/5G

----------------------------------------------------------------
4. 工業通訊標準與資訊模型 (★AIoT 新增)
----------------------------------------------------------------
* OPC UA: 工業互操作標準、跨平台、支援資訊模型 (語意化)
* MTConnect: 工具機/設備資料標準 (製造設備聯網)
* Modbus: 傳統工業通訊協定 (RTU/TCP), 簡單常用
* 資訊模型: 讓不同設備資料有一致語意 (如 OPC UA Information Model)
* 常見機聯網方案: WebAccess、CIMFORCE、VMX、Skymars 等

----------------------------------------------------------------
5. 中介軟體與平台
----------------------------------------------------------------
* 中介軟體 Middleware: 連接裝置與應用, 處理通訊/資料轉換
* IoT 平台: 裝置管理、資料收集、規則引擎、視覺化
* 雲端服務平台: AWS IoT, Azure IoT, Google Cloud IoT
* EPCglobal: 供應鏈 RFID 標準架構 (標籤→讀取器→中介軟體→EPCIS)

----------------------------------------------------------------
6. 資安與隱私基本概念
----------------------------------------------------------------
* 常見風險: 資料外洩、設備入侵、殭屍網路 (Mirai)、中間人攻擊
* 基本防護: 身分驗證、加密傳輸 (TLS)、韌體更新、最小權限
* 隱私: 個資保護、去識別化

----------------------------------------------------------------
7. 感測器原理與應用 (★考科一共同範圍)
----------------------------------------------------------------
* 感測器種類: 溫度、濕度、壓力、光、加速度、陀螺儀、氣體、
    超音波、紅外線、影像 (CMOS)
* 訊號型態: 類比 (連續, 電壓/電流) / 數位 (離散)
* 訊號調節 Signal Conditioning:
    - 放大 (Amplifier)、濾波 (濾高頻雜訊)、隔離
    - 類比數位轉換 ADC: 取樣 (Sampling) + 量化 (Quantization)
* 傳輸介面 (★):
    - UART: 非同步序列, 點對點 (TX/RX)
    - I²C: 兩線 (SDA/SCL), 多裝置、有位址
    - SPI: 四線 (MOSI/MISO/SCK/SS), 高速、全雙工
* 常用開發板: Arduino (入門/控制)、Raspberry Pi (Linux/運算)、
    Micro:bit (教育)
