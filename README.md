# iPAS AI 應用規劃師 備考資料

個人準備 iPAS AI 應用規劃師（初級／中級）與 AIoT 應用工程師（物聯網類）能力鑑定的整理筆記與資源清單。

## 📂 目錄結構

```
.
├── 五日備考計畫/          # 5 天衝刺重點（AI 3 天 + IoT 2 天）
│   ├── Day1_機器學習基礎與深度學習.txt
│   ├── Day2_生成式AI與LLM應用.txt
│   ├── Day3_資料處理統計與AI治理.txt
│   ├── Day4_AIoT基礎概論.txt          # iPAS AIoT 應用工程師（物聯網類）考科一
│   └── Day5_物聯網系統與應用.txt      # iPAS AIoT 應用工程師（物聯網類）考科二
│
└── 考古題資料/
    ├── 資源清單.md         # 官方／社群／線上題庫資源整理
    └── 網路收集_社群回憶版/ # 社群分享的考試回憶題
```

> 註：官方 PDF 教材與試題因版權考量未納入版本控制（見 `.gitignore`），請至 [iPAS 官方網站](https://ipd.nat.gov.tw/ipas/certification/AIAP/learning-resources) 下載。

## 🎯 考試範圍

### 初級 — AI 應用規劃師
- 科目 1：人工智慧基礎概論
- 科目 2：生成式 AI 應用與規劃

### 中級 — AI 應用規劃師
- 科目 1：人工智慧技術應用與規劃
- 科目 2：大數據處理分析與應用
- 科目 3：機器學習技術與應用

### 初級 — AIoT 應用工程師（物聯網類）
> 自 115/1/1 起「物聯網應用工程師」停辦，改由「AIoT 應用工程師」承接。
- 考科一：AIoT 基礎概論（學科）
- 考科二：物聯網系統與應用（學科）
- 考科三：機器聯網基礎應用實作（術科）
- 考科四：感測器信號調節實務應用（術科）

## 🌐 線上答題練習

本 repo 內附純前端答題練習網站（`docs/`），可部署於 GitHub Pages：

- 多科目題庫（初級 / 中級各科；含初級 AIoT 物聯網類 597 題歷屆試題）
- 四種模式：逐題練習、模擬考、隨機抽題、錯題複習
- localStorage 自動存進度與錯題本
- 可選搭配 Google Apps Script 將作答結果集中至 Google Sheet

部署說明見 [`docs/README_deploy.md`](docs/README_deploy.md)。
